Eclipse update site

You are looking at an Eclipse p2 update site, not a web page. It is meant to be opened by Eclipse rather than by a browser, so copy the address below into Eclipse instead of browsing it here.

Install the plug-in

  1. In Eclipse, open Help → Install New Software…
  2. Click Add… next to the Work with field.
  3. Paste this location and give it a name such as Pull Request Review:
https://philipp0205.github.io/eclipse-pull-request-plugin/p2/
  1. Select Pull Request Review from the list.
  2. Click Next, accept the license, and finish the wizard.
  3. Restart Eclipse when prompted.

EGit must already be installed, because this site contains only the Pull Request Review plug-in and not the Eclipse platform itself.

If Eclipse cannot read the site

Eclipse caches update-site metadata, including failures. Remove the entry under Preferences → Install/Update → Available Software Sites, then add the address again rather than editing the old entry.
